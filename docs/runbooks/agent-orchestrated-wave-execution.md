# Runbook: Human-Orchestrated Wave Execution

Purpose: Run a bounded qualification batch across the reference corpus using deterministic orchestration plus human-driven coding-agent slice loops.

## Steps

1. Build the qualification queue.
2. Generate handoff packets for ready slices.
3. Assign slices to developers.
4. Developers choose coding agents and submit bounded changes.
5. Run deterministic validation and record evidence.
6. Retry, escalate, or advance slices based on outcomes.
