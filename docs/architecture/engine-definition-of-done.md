# Engine Definition of Done

1. The engine can ingest and classify a whole logical COBOL program composed of many files.
2. The engine can lower parsed artifacts into IR.
3. The engine can decompose the program into bounded slices.
4. The engine can generate baseline Java and Spring scaffolds targeting one Spring Boot microservice.
5. The engine can emit bounded human handoff packets for one ready slice.
6. The engine can persist operator, prompt summary, diff, and disposition metadata.
7. The engine can run deterministic validation after every human-submitted agent pass.
8. The engine can produce program-level evidence and acceptance state.
